## 變更

- README 整合目前架構圖、模組功能、四個服務位址、啟動順序、保存規則、驗收與未完成範圍。
- 新增 [系統待辦](backlog.md)，涵蓋幹員庫、批次、基建、養成、搭配、設定、匯入、OCR／影片、圖鑑 API、手機與發布。列出優先級、來源與完成條件；未實作項目保持未勾選。
- UI 將「裝備技能」改為「選用技能」，空選項改為「未選用」；模組仍稱「裝備模組／未裝備」。
- 無模組資料顯示「沒有模組資料」；只有原始證章時顯示沒有可升級模組資料。篩選後無待確認欄位不會誤判成沒有模組。
- 排除私人研究檔、圖片、快取及工具目錄；泛化個人路徑與私人檔案識別資訊，模組驗證 JSON 只保留統計。未提交的本機截圖改為文字證據註記，避免留下失效的圖片連結。
