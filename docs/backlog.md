# 系統缺口與後續待辦

盤點日期：2026-11-13。範圍涵蓋六個主頁簽、匯入與研究服務、圖鑑 API、保存／備份、手機操作及原始實作計畫。此表是後續工作清單，**本次只完成盤點與文件整理，未實作以下未勾選功能**。

需求依據為使用者提供的 `arknights_tw_codex_implementation_plan.md` §7、§9–12、§14；私人原檔與個人路徑不隨儲存庫提供。程式證據連到本版來源。靜態判讀的風險不冒充已重現故障；iPhone 項目仍須真機。

## 目前完成到哪裡

| 模組 | 已有能力 | 主要缺口 |
| --- | --- | --- |
| 幹員庫／圖鑑 | 大量匯入、查詢、詳情、技能／天賦／模組、欄位證據 | 真實欄位語意與完整持有數未驗收；圖鑑版本缺漏提示不足 |

## 優先順序

- **P0：可用性與資料可信度門檻。** 優先解決，通過前不宣稱正式手機工具或完整自動匯入。
- **P1：核心功能與可靠性。** 前置資料確認後，依原計畫先做基建，再做養成與搭配。
- **P2：擴充與操作改善。** 不阻擋本機研究原型，但正式交付前須按用途評估。

以下皆為未完成待辦；優先級是本次盤點建議，沒有替使用者決定部署、付費或帳號授權方案。
