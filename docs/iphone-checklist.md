分別記錄 Safari 與加入主畫面模式；預設不認定兩者共用資料。正式手機網址與 HTTPS 方案尚未選定。本機 Windows 的 `127.0.0.1` 只指向該 Windows 主機，不能直接在 iPhone 使用同一網址。先確認一個使用者選定的測試存取方案，再測試。

## 本輪幹員庫與保存

- [ ] 直向／橫向，最小 360 CSS px、瀏海安全區、文字放大 200%，按鈕可點、不被底部導覽蓋住、沒有橫向捲動。
- [ ] 開啟空個人庫與示範庫，兩者醒目區分；切換後資料不互相污染。
- [ ] 從「檔案」選取本工具 JSON；先預覽、取消、再匯入，不在確認前寫入。
- [ ] 重複及局部匯入不新增重複幹員，不移除沒有出現的幹員。
- [ ] 舊值／新值、人工確認與低信心衝突逐欄可確認，未知專精不顯示為零。
- [ ] 合併後重整、關閉分頁、完全結束 Safari、重開、重啟手機，資料仍可讀取。
- [ ] 兩個分頁開啟同一資料庫；舊分頁提交時被阻擋並要求重載，不覆蓋新資料。
- [ ] 撤銷最近一批後重開，幹員資料回到之前狀態且批次紀錄保留。
- [ ] 備份下載能在「檔案」找到；最近備份時間只是下載發起紀錄，需人工確認檔案可開啟。
- [ ] 合法備份復原前看見差異，確認後欄位、未知狀態、人工更正及設定一致。
- [ ] 不合法 JSON、錯誤服別、未來版本、校驗失敗、超過大小限制均拒絕，原庫不變。
- [ ] 切換 Safari／主畫面版本及另一台裝置，以明確匯出／復原驗證移轉，不假設自動同步。
- [ ] 低容量／儲存拒絕／隱私瀏覽模式，顯示實際錯誤；不得顯示已保存或清空舊庫。
- [ ] 查詢容量與請求持久儲存；記錄 API 不支援、拒絕或接受，仍提示自行備份。
- [ ] 斷網後目前頁面可否繼續操作、重開能否載入，分開記錄。本輪尚未實作 Service Worker／離線資源快取，不能宣稱離線重開可用。
- [ ] 更新網站程式／資料格式前先備份，升級失敗保留原資料；舊版本不強行打開新格式。
