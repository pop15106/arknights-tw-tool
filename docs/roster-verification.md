# 幹員庫功能與捲動修正驗證

日期：2026-11-13（Asia/Taipei）。範圍限幹員庫、圖鑑詳情與既有匯入／保存流程；基建、養成建議、搭配規則仍未實作。

## 已完成

- 搜尋中文名稱、別名與幹員 ID，忽略前後空白及英文字母大小寫。
- 職業、星級、精英階段及資料狀態交集篩選；未知與來源值待核對分別選擇。
- 依 ID、中文名稱、星級或精英／等級排序；養成排序各層已知值在前，同序按穩定 ID 排列，不變更資料。
- 每頁最多 48 名，顯示範圍與總數；改篩選回第一頁，換頁回列表標題；可一鍵清除篩選。
- 肖像按原圖比例完整縮放；合法本機圖片載入失敗可重試。
- 詳情提供中文技能、等級說明、天賦與條件；正文獨立捲動，標題及完成按鈕保持可見。
- 人工修正維持預覽及衝突確認，取消不保存；保存、重開、撤銷及備份復原沿用既有交易保護。

## 根因與修正

1. **主頁無法捲動**：現場觀察無對話框時，`body.style.overflow` 仍為 `hidden`，內容高 86,490px、可視高 562px。原本每個 Modal 各自保存／還原 overflow，匯入與預覽交替掛載時可能保存到另一個 Modal 的鎖定值。改由唯一 App 父層依「是否有對話框」管理鎖定，切換面板不重新擷取鎖定值。
2. **肖像被裁切**：現場圖片元素高 310.208px，父容器僅 90px。Grid 的內在尺寸把圖片撐出容器。改為 Flex 尺寸約束與 `object-fit: contain`，圖片長寬屬性改為實際 180×360；桌面驗證圖片與父容器同高 132px，手機同高 116px。
3. **部分圖片失敗後無法恢復**：原實作一旦 `onError` 就只顯示替代文字。現在有效本機路徑可明確重試，不對非法來源發請求。先前截圖的個別載入失敗原因未完整捕捉；本輪不將其推定為檔案遺失。

- 圖片重試控制已實作，但本輪未以人工破壞圖片檔案注入失敗；確認的是全部正常圖片的服務與顯示。
